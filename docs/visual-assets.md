# Визуалы для сайта MKZV WEB

Это карта плейсхолдеров: что именно туда лучше вставлять, чтобы сайт продавал, а не просто выглядел красиво.

## 02. Быстрые сигналы

### Оффер без шума

Нужен скрин первого экрана сайта или макет в стиле “до / после”: крупный оффер, короткое пояснение, CTA, 1–2 маркера доверия. Это не абстрактная картинка, а доказательство, что ты умеешь быстро объяснять ценность.

Подойдут:

- скрин hero-блока будущего кейса;
- затемнённый wireframe первого экрана;
- Figma/mockup с сеткой, заголовком и CTA;
- до/после: хаотичный блок → чистая структура.

### Заявка на телефоне

Нужен мобильный мокап: экран телефона с формой, кнопкой, Telegram-контактом или коротким брифом. Смысл блока — показать, что мобильная версия проектируется первой.

Подойдут:

- mockup iPhone/Android с формой заявки;
- скрин мобильного лендинга;
- карточка “имя / задача / контакт / отправить”;
- маленькая схема пути: экран → форма → Telegram.

## 08. Избранные проекты

### Здесь будут реальные кейсы

Нужен сильный визуал кейса: крупный фрагмент сайта, экран интерфейса, сетка компонентов, брендовый первый экран. Это главный “доказательный” визуал.

Подойдут:

- 2–3 скрина сайта, собранные в один постер;
- темный mockup веб-страницы;
- сетка интерфейсных компонентов;
- before/after одного проекта.

### Рост доверия

Нужна не буквальная статистика, а визуальный сигнал результата: график, карточки метрик, структура “роль / стек / результат”, аккуратная диаграмма.

Подойдут:

- dashboard-like карточка с метриками;
- график заявок/конверсии как декоративный слой;
- карточка “роль / стек / результат”;
- схема пути пользователя до заявки.

## Общий стиль

- Чёрный / тёмно-серый фон.
- Белая или серая графика.
- Много сетки, шума, технических линий.
- Без ярких цветов.
- Лучше использовать реальные скриншоты, но пока можно делать AI/placeholder-визуалы в той же стилистике.
