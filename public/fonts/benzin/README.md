# Benzin webfont files

Place licensed Benzin webfont files here:

- Benzin-Regular.woff2
- Benzin-Medium.woff2
- Benzin-Semibold.woff2
- Benzin-Bold.woff2
- Benzin-ExtraBold.woff2

The site uses `Benzin` for the full typography system: body text, display headings, technical labels, buttons, and form fields. IBM Plex stays only as a fallback until the licensed files are added.
